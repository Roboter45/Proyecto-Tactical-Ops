Base en Pyxel, sprites iniciales, mapas y navegación entre pantallas 

~20 % del tiempo total

3. Implementación 

Combate por turnos, campaña, diálogos, inventario, tienda y jefe final 

~35 % del tiempo total 

Campaña completa con todas las mecánicas integradas 

4. Pruebas y ajuste 

Depuración de errores, pruebas de flujo y balance de combate/economía 

~15 % del tiempo total 

Versión estable y probada de principio a fin 

5. Documentación y cierre 

Memoria final, revisión de código y preparación de defensa/demostración 

~15 % del tiempo total 

Proyecto y documentación listos para entrega
